WHAT THIS PROJECT IS
--------------------
Weekly candlestick chart of the Italian BTP bond IT000553414, built with
pandas + plotly, exported to PLOT.html. The user downloads fresh price data
into data.csv (daily OHLC, Investing.com-style format: MM/DD/YYYY, quoted
numbers, utf-8-sig BOM, newest row first) and rebuilds the chart.

Storyline in the data (2026 YTD): Jan-Feb rally to ~106 on rate-cut bets ->
US-Israel war on Iran erupts Feb 27-28, Hormuz shut, oil spikes -> BTP crashes
to YTD low 96.60 (late Mar) -> ceasefire relief rallies and truce-break
selloffs alternate -> ECB first hike since 2023 (Jun 11, to 2.25%) -> renewed
strikes in July -> ECB holds 2.25% on Jul 23 -> last close 97.66 (Fri Jul 24).

   Run `python3 update.py` after downloading new data.csv. It prints:

     3. FORECAST — per forecast week: completed weeks scored HIT/MISS
        (actual close within forecast Low-High ±0.05 AND same candle
        direction); plus anchor-drift check: if the latest weekly close moved
        more than REANCHOR_TOLERANCE = 0.30 pts from anchor_close, verdict
        is REVIEW / RE-ANCHOR, else KEEP.
   update.py is read-only by design: it diagnoses, humans/Claude edit the
   xlsx files, then `python3 run.py` rebuilds.

3) RESTRUCTURED forecast.xlsx SCHEMA  [v2, session 2026-07-27]
   forecast.xlsx is an APPEND-ONLY LOG of every forecast vintage.
   Columns: week_end (absolute Friday date), Open, High, Low, Close, icon,
   text, made_on, anchor_close, note.
   - A "vintage" = all rows sharing one made_on/anchor_close.
   - NEVER delete rows. On re-anchor: append the new vintage's rows; on the
     old vintage, mark replaced upcoming rows note="superseded by <date>
     re-anchor (...)", and write a POST-MORTEM note on every completed week
     that MISSED (why it missed + lesson) — this is the learning loop.
   - run.py plots only the LATEST vintage (max made_on), and within it only
     rows with week_end > last actual weekly date.
   - update.py: section 3 judges only the latest vintage (KEEP/RE-ANCHOR);
     section 4 "FORECAST TRACK RECORD" scores every vintage HIT/MISS,
     prints notes, flags misses lacking a note (that's a REVIEW problem),
     and prints a running hit-rate score.
   Track record so far: 1/1 (vintage 2026-07-24 week 07-31: mid-week MISS
   flip-flopped to FINAL HIT at Friday close 97.18 — full saga + lessons in
   its note).
